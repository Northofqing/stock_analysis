**Status:** Gate B input evidence; not migration authority

## Purpose

The global schema reference builder requires an independent, checked-in
`ddl_id -> exact SQLite SQL bytes` input. The identity-only catalog could not
execute a same-runtime reference database and must not invent SQL from object
names.

This evidence freezes only the historical `sqlite_schema.sql` bytes. It
contains no table rows and is never regenerated by production startup,
classification, migration or tests.

## Capture

The source was the fixed historical production database in its unmanaged
identity:

```text
application_id = 0
user_version = 0
integrity_check = ok
named application objects = 160
tables = 53
indexes = 44
triggers = 63
```

The database was opened using SQLite URI `mode=ro&immutable=1`. The query read
only non-NULL `sqlite_schema.sql` rows whose names do not begin with
`sqlite_`. The resulting `(type,name,tbl_name)` set was required to equal the
already frozen identity registry exactly before any fixture was written.

`src/database/fixtures/global_schema_legacy_ddl_v1.tsv`. SQL bytes are
uppercase hexadecimal so delimiters, whitespace, quotes and trigger bodies
remain byte-exact and unambiguous.

## Runtime Contract

The strict parser must:

1. accept exactly two nonempty fields per data row;
2. reject invalid or odd-length hexadecimal;
3. decode valid UTF-8 with no NUL;
4. require a one-to-one match with every frozen legacy `ddl_id`;
5. reject missing, duplicate and unknown IDs;
6. execute each decoded statement exactly once in registry order in an
   isolated same-linked-runtime SQLite database;
7. compare SQLite-emitted catalog bytes and ancillary index geometry against
   the reference.

Actual production databases, temp copies and callers cannot supply expected
SQL or construct the opaque reference capability.

## Rollback

Before production migration, revert the fixture, parser and reference-builder
commit together. Do not alter, truncate, attach or rewrite the source
database, its audit files or any account/order evidence.
