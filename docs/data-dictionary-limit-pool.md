## streak 口径验证（2026-11-07，生产库只读）

方法：若 `streak` 是连续涨停天数，则「本次连续在池段的起点 streak + 天数差」
应等于当日 streak；若是「N 天 M 板」的累计板数，则更接近最近 5 个快照出现次数。
窗口 2026-10-26 ~ 11-06（10 个快照日，每日 32~125 只）。

结果：

- 可独立验证样本 **109 只**（`streak>=2`，且连续段起点早于当日）：
  **109/109** 等于「起点 streak + 天数差」。
- 同一批样本，等于「最近 5 个快照出现次数」的只有约 72%。
- 典型样本：`002578` 11-02 streak=1 → 11-03=2 → 11-04=3 → 11-05=4 → 11-06=5，
  连续 5 个交易日在池；`601599` 同型。

结论：**`streak` = 连续涨停天数**，不是「N 天 M 板」累计数。

## 边界

1. 库窗口从 2026-10-26 开始，早于此的连板历史不可见（左截断），
   只能用当日 streak 做锚点，无法独立验证。
2. 桥接层只落映射后的字段，原始响应（如「几天几板」字符串）未留存；
   若怀疑桥接映射变化，需要桥接侧 raws 才能进一步定位。
3. `board_name` 在窗口内全为 NULL，任何依赖板块名的逻辑都不能假设它有值。
4. 每日只数 32~125 只，弱市日样本少；streak>=4 的样本更少（窗口内最大 6），
   高位门阈值 4 的统计意义有限。
